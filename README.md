# Unstuck Coach

A folder-based whole-person executive-function accessibility coach for people who need help starting, switching, remembering, regulating, capturing, recovering, and closing loops without shame.

Drop this folder into a Claude Project, Codex workspace, AI IDE project, or local-model context and ask the coach to help with the life loop in front of you.

## Who this is for

People who already have values, obligations, care, and intelligence, but lose traction at the executive-function layer (initiation, switching, time, re-entry, shame after avoidance, inbox/calendar drift).

## Repository boundary

This repository is the **Unstuck Coach protocol / publication artifact**: the folder-based coach contract, identity, rules, examples, and supporting docs.

It is **not** the hosted Unstuck product app and **not** Innerscape.

Sibling protocol surface: [KyaniteLabs/unstuck-coach-protocol](https://github.com/KyaniteLabs/unstuck-coach-protocol).
